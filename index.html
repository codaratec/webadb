 Before you connect

            
    
                
  1. Use a compatible browser
    Open this page in desktop Chrome or Edge over HTTPS or localhost. WebUSB is required.
    2. 
                
  2. Enable USB debugging
    On Android, enable Developer options and USB debugging. Connect a USB data cable, unlock the device and approve the debugging prompt.
    3. 
                
  3. Free the USB connection
    Close desktop ADB and other tools using the device. On Windows, install the Android device's USB driver if the connection fails.
    4. 
            

            

                USB picker shows no compatible devices?
                
A charging connection alone is not enough. The computer must detect the phone's USB data connection and Android's ADB interface.

                
    
                    
  • Try a USB data cable and a direct computer USB port. Select File transfer on Android to check that the computer can see the phone, then reconnect with USB debugging enabled.
    • 
                    
  • On Windows, check Device Manager for an Android ADB interface. If it is missing, check the cable and your manufacturer's ADB USB driver.
    • 
                    
  • If another ADB tool can detect the phone, close that tool before connecting here.
    • 
                

            

            
The ADB authentication key is saved in this browser for future connections. Forget it when using a shared computer; Android may ask you to authorize again.
